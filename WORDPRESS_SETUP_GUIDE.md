## 🚀 How to Install on WordPress

### Method 1: Upload via WordPress Admin (Recommended)
1. Go to your WordPress Admin Dashboard: `https://yourdomain.com/wp-admin/`
2. Navigate to **Appearance > Themes > Add New Theme > Upload Theme**.
3. Choose the [`aiman-collection.zip`](file:///c:/Users/Lenovo/Desktop/Aiman%20Collectiion/aiman-collection.zip) file and click **Install Now**.
4. Click **Activate**.

### Method 2: Manual / Localhost / FTP
1. Copy the folder `wp-content/themes/aiman-collection` into your WordPress installation's `wp-content/themes/` directory.
2. In WordPress Admin, go to **Appearance > Themes** and activate **Aiman Collection**.
